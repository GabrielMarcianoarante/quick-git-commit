# Contribuindo

Pull requests com alterações de código estão pausados por enquanto. Eles poderão ser aceitos quando houver um acordo de contribuição (CLA) que defina os termos para contribuições ao projeto.

Issues e sugestões continuam abertas. Use-as para relatar problemas, propor melhorias ou compartilhar ideias. Por favor, não abra pull requests de código até que o projeto anuncie a reabertura das contribuições.

Quando as contribuições forem reabertas, este guia será atualizado com as instruções para contribuir.
