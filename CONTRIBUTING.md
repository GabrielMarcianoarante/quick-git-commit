# Contribuindo / Contributing

## Português

Obrigado pelo interesse no Quick Git Commit.

**Pull Requests ainda não são aceitos.** O projeto é distribuído sob a licença PolyForm Noncommercial 1.0.0 e planeja ter uma versão paga (Pro) no futuro. Para que contribuições de código possam ser incorporadas a ela, precisamos antes de um acordo de contribuição (CLA), no qual quem contribui concede ao autor o direito de usar, modificar e licenciar o código enviado, inclusive comercialmente. Esse acordo será publicado aqui e as contribuições abrirão depois disso.

Enquanto isso, você pode ajudar:

- **Relatando problemas:** abra uma issue com os passos para reproduzir, a versão do VS Code, o sistema operacional e, se possível, o texto de **Ver > Saída > Quick Git Commit**.
- **Sugerindo funções:** descreva o problema que você quer resolver, não só a solução.
- **Votando:** reaja com um polegar para cima nas issues mais importantes para você.

Pull Requests enviados antes da publicação do acordo poderão ser fechados sem análise.

## English

Thanks for your interest in Quick Git Commit.

**Pull Requests are not accepted yet.** The project is distributed under the PolyForm Noncommercial License 1.0.0 and plans to offer a paid (Pro) version in the future. So that code contributions can be included in it, a Contributor License Agreement (CLA) is needed first, in which contributors grant the author the right to use, modify and license the submitted code, including commercially. The agreement will be published here, and contributions will open after that.

In the meantime you can help by:

- **Reporting bugs:** open an issue with reproduction steps, your VS Code version, your operating system and, if possible, the output from **View > Output > Quick Git Commit**.
- **Suggesting features:** describe the problem you want solved, not just the solution.
- **Voting:** add a thumbs-up to the issues that matter most to you.

Pull Requests sent before the agreement is published may be closed without review.
